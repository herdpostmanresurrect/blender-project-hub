## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Project Library** | Organize Blender projects with deadline and client information |
| **Addon Manager** | Track installed Blender addons with version and category notes |
| **Render Profiles** | Save named render setting configurations per project type |
| **Asset Tracker** | Log linked assets and textures across your Blender projects |
